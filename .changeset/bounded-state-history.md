**`stateHistory: {blocks: N}`: state reads at recent past blocks.** A new, opt-in `createNode` option. With it, the node answers every state read pinned to any of the last N blocks below its head (plus the head) exactly as a node holding that block's state would, on both engines, so `eth_getLogs` up to block K and `eth_call` at block K describe the same moment even after the head has moved on.

- **Point reads in the window.** `eth_getBalance`, `eth_getCode`, `eth_getStorageAt` and `eth_getTransactionCount` at a block K in the window return the values at the end of K, whichever way K is named (number, hash, EIP-1898 `{blockNumber}` / `{blockHash}`, `earliest` while block 0 is in the window).
- **`eth_call` and `eth_estimateGas` execute at K**: against K's state and K's block environment (`NUMBER`, `TIMESTAMP`, `COINBASE`, `PREVRANDAO`, `BASEFEE`, `GASLIMIT`; `BLOCKHASH` of K and above is zero), with state overrides applied on top of K's state. Nothing they do changes the head or the past.
- **Beyond the window, still refused** with `-32000 historical state not available`, and the message now names the oldest block the node can serve and the option that widens it. Without the option nothing changes: the head is served and every block below it is refused, as the entry on pinned reads describes.
- **Persisted.** `dumpState` carries the history as a new optional `history` field (the format stays `version: 1`) and `loadState` restores it, so an IndexedDB reload serves the same window. An older dump, or one written by a node without the option, still loads, with history starting at its head; a dump holding more blocks than the loading node's N is cut to N. A node without the option writes no `history` field, so its dump is unchanged.
- **Works through every transport.** The option passes through `createWorkerNode` / `exposeNode`, and historical reads over a port handed to `node.serveOn(port)` answer as `node.request` does.
- **Bounded, and measured.** The node keeps an undo log of the last N blocks (for each key a block changed, the value before it), evicting older records as blocks are mined. About 300 bytes per changed key per retained block, no measurable cost per block, and a historical `eth_call` costs about 0.8 µs per distinct key changed since K; the README's "What it costs" section has the figures and a sizing example. Refused at construction for any value other than `{blocks: <positive safe integer>}`. Works with and without `computeStateRoot` (see the entry on the derived trie).
