**New package: `@webevm/devnode`, dev accounts for webevm, funded at genesis.** `createDevNode(options)` creates a webevm node (every `createNode` option is accepted) whose `eth_accounts` answers with anvil's and Hardhat's ten default test accounts (the standard test mnemonic, `m/44'/60'/0'/0/i`), each holding 10,000 ETH at block 0, so index-declared accounts resolve to the same addresses as on those nodes. The accounts are configurable as `{mnemonic, count, path, initialIndex}`, a count, or a list of private keys; `balance` sets their genesis balance, `fund: false` funds none, and `fundAccounts` funds extra addresses (anvil's `--fund-accounts`), all merged into webevm's `initialBalances` with the caller's own entries winning. A chain restored by `loadState` or persistence keeps its own balances. `wrapDevNode(node, {accounts})` wraps a node that already exists and funds nothing; `devAccountBalances(options)` returns the `initialBalances` the same options would fund, for a node created elsewhere. The result is a `SlimNode`: every method it does not implement reaches the node unchanged (its errors, `-32601` included), `serveOn` serves the dev node's own `request`, and `dispose` closes the ports it served before disposing the node. `webevm` (`>=0.9.1`) is a peer dependency. Sending, signing, impersonation and an alloc export come in later releases.
